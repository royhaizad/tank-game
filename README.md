# Tank Game

A **Tank Trouble-inspired**, top-down 2D tank duel — one player vs. one AI opponent, inside a randomly generated maze, with bouncing bullets as the signature mechanic.

Built solo, no coding background, using **Claude Code** as the development partner.

---

## What This Project Does

- **Single-player vs. AI**, with 3 selectable difficulty tiers (Easy / Medium / Hard)
- **Bullets ricochet off walls** instead of disappearing — the same signature mechanic as the original Tank Trouble
- **Random maze generation** — a new layout every match
- **Power-up system** — Gatling Gun, Shotgun, Homing Missile, Shield, Mine, Laser
- **Pixel art style**, inspired by Stardew Valley's warm, hand-painted look
- Runs **100% in the browser**, client-side only — no server, no login, no internet required after download

---

## Why This Project Exists

A personal project to relearn and recreate the addictive, simple-but-skillful gameplay of classic browser games (Tank Trouble, Territory War, Brotato, and similar) — built by a UI/UX designer with no prior coding background, using AI-assisted development end to end.

**Goals for this game:**
1. Play offline on a phone, anytime, anywhere
2. Share a working copy with friends via direct file transfer
3. Play local couch co-op on desktop, 1–4 players, no internet required

---

## Getting Started

No installation, no build tools, no dependencies required.

1. Clone or download this repository
2. Open `index.html` directly in any modern browser
3. Play

```bash
git clone https://github.com/royhaizad/tank-game.git
cd tank-game
# then just open index.html in your browser
```

### Controls
| Action | Key |
|---|---|
| Move | WASD / Arrow Keys |
| Fire | Spacebar |
| Pause | Esc |
